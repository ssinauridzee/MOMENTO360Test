# MOMENTO 360 Android v0.8 — ორი ტაბი: 360 / GoPro

ეს არის მომხმარებლის მიერ მოწოდებული MOMENTO 360 Android v0.7 პროექტის გაგრძელება.

## 360 ტაბი
- ქვედა ნავიგაცია: **360** და **GoPro**.
- BLE დაკავშირება `360Tok-00772`-თან, სერვისი `FFE0`, ბრძანებები `FFE1`.
- ერთი მრგვალი START/STOP, ორი მიმართულება (ნორმალური `03 01`, უკუ `03 00`), სიჩქარე 1–6, დროით ბრუნვა, LED ON/OFF, Colors/CCT/Loop, სიკაშკაშე.
- **GoPro სინქრონიზაცია** თავდაპირველად ჩართულია: GoPro-ის shutter START-ის წარმატებული პასუხის შემდეგ იწყება ძრავა. STOP ან დროის ამოწურვა აგზავნის STOP-ს ორივეზე.
- GoPro-ის გარეშე მხოლოდ 360-ის სამართავად გამორთე სინქრონიზაციის გადამრთველი.
- სინქრონიზაცია მუშაობს microSD რეჟიმით; SD-ის გარეშე Wi‑Fi Preview ცალკეა GoPro ტაბში.

## GoPro ტაბი
- v0.7-ის ყველა არსებული ნაწილი: BLE დაკავშირება, Wi‑Fi AP-ის ჩართვის მოთხოვნა, microSD/Wi‑Fi Preview რეჟიმები, Slow Motion-ის დრო/ფანჯარა/სიჩქარე, Preview TS/MP4 ექსპორტი, მომზადებული ვიდეოს შენახვა, საიტის API, ატვირთვის რიგი, ლინკი/QR/SMS.
- დამატებულია GoPro HERO9-ის Video Resolution და FPS ბრძანებების BLE სექცია (GoPro მხოლოდ მაშინ მიიღებს, თუ მიმდინარე Preset მხარს უჭერს კომბინაციას).

## ინსტალაცია / უსაფრთხოება
- ახალი ID: `ge.momento.booth.tabs`, ამიტომ შეიძლება არსებული v0.7-ისა და ძველი ძრავის აპის გვერდით დაყენება. API გასაღები ამ ვერსიაში თავიდან შეიყვანე.
- WordPress Gallery v0.6.2 პლაგინი უცვლელად დატოვე.
- კამერისა და ძრავის ერთობლივი მუშაობა რეალურ მოწყობილობებზე ჯერ ხელახლა უნდა შემოწმდეს. პირველ ცდაზე პლატფორმა ცარიელი გქონდეს და ფიზიკური STOP პულტი მზად.
- Wi-Fi Preview-ის შესაძლებლობა, SD ბარათის გარეშე, დამოკიდებულია GoPro firmware-ზე.
