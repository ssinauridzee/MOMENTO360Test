# ტაო-კლარჯეთი — Android გზამკვლევი

ქართული ოფლაინ ისტორიული მეგზური 11 ადგილისთვის — საძიებო ველი, თანამედროვე ბარათები, ისტორიის გახსნა/დაკეცვა, მთავარი ფაქტები, სრული ისტორია, წყაროები, რუკის ღილაკები.

Source archive is stored in `project.tar.xz.b64` as Base64-wrapped xz tarball. The Actions workflow unpacks it and compiles the Android APK. Java 17, Android SDK 35, Gradle 8.10.2.

## APK
Open the **Actions** tab > **Tao Klarjeti Android APK** > latest run > **Artifacts** > **TaoKlarjeti-Android-APK**. Unzip and install `tao-klarjeti-guide.apk` on Android. The main branch of this repository was not changed.
